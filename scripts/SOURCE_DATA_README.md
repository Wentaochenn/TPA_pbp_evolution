# Figure source data

Each figure has a directory containing its panels. `PANEL_DATA_INDEX.tsv` maps panels to their source files. Tables retain the analytical values used in the figures; `rendered_layers/` additionally records the data passed to individual R plotting layers.

Variant frequencies use callable genomes as the denominator. Protein-type frequencies use genomes with an assigned protein type. Date summaries retain their original clock model and interval definitions. FUBAR values are posterior probabilities. ESM-2 values are alternate-versus-reference log-likelihood ratios.
